# 08 · 市场对照验证：最重要的一份文档

**先读这份，再决定要不要继续开发。**

这轮工作做了一件之前从没做过的事：**用真实历史赔率，检验模型有没有真的比市场准**。结果决定了整个项目的价值定位，所以放在最前面。

---

## 一句话结论

**模型目前打不过市场。按现有状态下真钱，会亏钱。**

不是"再调调参数"的问题——已经系统性排除了策略层面的所有变量。缺口在模型本身的预测精度。

---

## 判定标准（开工前跟用户约定，事后没有改）

1. 模型 RPS **必须低于**市场赔率的 RPS（不是接近，是低于）
2. 平注 ROI **必须 > 0**

第1条没过就不用测第2条。

---

## 核心数字

### 基础对照（四大联赛，1267场保留集）

| | 准确率 | RPS |
|---|---|---|
| 静态 MLE | 48.9% | 0.2049 |
| + 贝叶斯更新 | 50.5% | 0.2004 |
| **市场赔率** | **53.3%** | **0.1913** |

模型比市场差 **0.0091**。

### 加 xG 之后（709场保留集）

| | 准确率 | RPS |
|---|---|---|
| 进球 MLE | 50.2% | 0.1990 |
| xG MLE | 49.4% | 0.1982 |
| 混合 | 49.9% | 0.1980 |
| **市场** | 50.9% | **0.1948** |

缺口缩小到 **0.0032**。xG 补掉了大约一半。

### 再加 Elo + 近期状态（651场保留集）

| | 准确率 | RPS |
|---|---|---|
| 进球 MLE | 49.9% | 0.2051 |
| xG MLE | 49.6% | 0.2024 |
| **集成（xG+Elo+Form5）** | **50.7%** | **0.2019** |
| **市场** | 50.5% | **0.1976** |

缺口 **0.0043**。集成的准确率超过了市场，但 RPS 仍落后。

**注意这个组合的含义**：猜对"谁赢"的次数不比市场少，但概率给得没市场准。下注赚不赚钱取决于概率准不准，不是猜对次数。

## 实际下注模拟（这是最直观的）

用真实历史赔率，完全按系统规则跑一个赛季：

| 策略 | 注数 | 命中率 | ROI | 最终资金（起始10,000）|
|---|---|---|---|---|
| 单场 EV>3% 半凯利 | 659 | 22.6% | **-13.9%** | 7 |
| 单场 EV>5% 全凯利 | 454 | 23.6% | **-15.1%** | 9 |
| 串关 2-6腿 EV>5% 全凯利 | 113 | **0.9%** | **-89.5%** | 2,019 |
| 用全市场最高赔率（抽水压到0.80%）| 818 | 26.3% | **-11.7%** | 6 |

**什么都不下的结局是 10,000，好过以上全部。**

### 串关为什么灾难性地更差

对独立事件 `EV组合 = Π(1+EV各腿) - 1`。模型高估每条腿的 EV 时，高估会**相乘复合**。

更糟的是**搜索逻辑在助纣为虐**：113注里55注是6腿——优化器挑"EV最高"的组合，而腿数越多、被高估的边际相乘越多、表面 EV 越高。**优化器会系统性地专挑误差放大最狠的组合。**

### 为什么 EV 门槛越高越差

3% → 5% → 10%，ROI 依次恶化。模型 EV 越高＝模型和市场分歧越大；模型是错的那一方时，分歧越大＝错得越离谱。**这是"模型没有优势"的典型指纹。**

## 已排除的变量（都测过，都不行）

| 变量 | 测试结果 |
|---|---|
| 仓位（半凯利/全凯利） | 全凯利更差 |
| EV 门槛（3%/5%/10%） | 越高越差 |
| 串关 vs 单场 | 串关差 6 倍 |
| 12个联赛（含英冠/英乙/西乙/意乙/德乙/法乙）| 全部输给市场，最接近的英冠也只是打平 |
| 赔率来源（平均 vs 全市场最高）| 改善 3.6 个百分点，不足以翻盘 |
| 赔率区间（1-2 / 2-3 / 3-5 / >5）| 3.0-5.0 区间最接近打平(-1.67%)，但仍为负，且大概率是扫了6个区间的统计假象 |

**低级别联赛这个常见假设不成立**——博彩公司在英乙的定价照样比我们准。

---

## 亏损的成分拆解（关键）

```
总亏损 15.3%  =  庄家抽水 4.7%  +  模型挑错边 10.6%
                     ↓ 比价可压到0.8%      ↓ 不变
改善后 11.7%  =  抽水 0.8%      +  模型挑错边 10.9%
```

**比价拿高赔率能解决抽水那部分，解决不了挑错边那部分。而后者占三分之二以上。**

## 还没试过的方向（以及诚实的预期）

| 方向 | 数据可得性 | 预期 |
|---|---|---|
| 伤病 / 首发阵容 | ⚠️ 免费源不可靠、更新慢 | 理论价值最高，但这正是市场信息优势最集中、我们最抢不过的地方 |
| 赛程密度 / 欧战疲劳 | ✅ 可从赛程自算 | 成本低，但增益预计小 |
| 主客场分离的攻防参数 | ✅ 用现有数据 | 未测，值得试，成本低 |
| 转会 / 换帅 | ⚠️ Transfermarkt 抓取受限 | 突变时关键，平时小 |
| 更新的 xG 数据（2022年后）| ⚠️ 现有GitHub数据集停在2021，understat.com 返回403 | 需要新数据源 |

**Elo 和近期状态已经试过，几乎没有增量**——它们本质也是从历史比分算的，跟 MLE 信息高度重叠。

---

## 给接手者的建议

**如果继续做模型改进：**

1. **必须换新的保留集**。当前这批 651-1267 场已经被用了三次，继续在上面试新特征会滑向过拟合。Understat 官网 403，需要找新数据源（`soccerdata` python 包、Kaggle、或付费 API）。
2. **优先试"主客场分离参数"**——成本最低、数据完全自有、且针对的是模型的真实结构性缺陷（现在只有一个全局主场优势常数，但球队的主客场表现差异各不相同）。
3. **每次只加一个特征，每次都在全新数据上验**。
4. **判定标准不要改**。RPS 低于市场 + 平注 ROI > 0，两条都过才算数。

**如果不再追求下注盈利：**

这套系统作为**赛事分析与记录工具**是完整可用的——预测、回测、虚拟盘、实盘记账、串关计算、资金曲线都正常工作。它刚刚还做了一件很有价值的事：在用户投一分钱之前，用真实数据证明了这个模型没有优势。

## 怎么复现这些结果

```bash
cd backend/training/validation
./00_build_xg_dataset.sh        # 下载 xG + 赔率原始数据
python3 01_model_vs_market.py   # 核心对照
python3 02_simulate_betting.py  # 下注模拟
python3 06_league_tiers.py      # 12个联赛扫描
python3 07_xg_experiment.py     # xG 实验
python3 08_ensemble.py          # 集成实验
```

**数据源**：
- xG：`douglasbc/scraping-understat-dataset`（射门级，2014-2021，五大联赛）
- 赔率+Elo+Form：`xgabora/Club-Football-Match-Data-2000-2025`（23万场，2000-2025，含 OddHome/MaxHome/HomeElo/Form5Home 等字段）

两个数据集靠 **日期 + 比分** 自动对齐队名（99.5%匹配率），映射表由 `07_xg_experiment.py` 自动推导，不需要手工维护。
