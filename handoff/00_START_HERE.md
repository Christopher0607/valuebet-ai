## 这个系统是什么

一个跑在本地的足球投注**数学分析工具**（不是自动下注机器人，见下方"重要边界"）：

- **数据**：自动从 GitHub 开源数据源抓取真实赛程和比分
- **模型**：Dixon-Coles 双变量泊松模型，球队的进攻/防守强度参数用最大似然估计（MLE）从 32,372 场真实历史比赛拟合而来
- **实时更新**：每场比赛结束后，用泊松-伽马共轭做贝叶斯增量更新，球队参数持续跟着最新战绩微调
- **投注计算**：用户手动输入赔率 → 系统算期望值（EV）和凯利公式建议仓位
- **串关推荐**：从多场比赛里自动搜索正期望值的 3-8 腿组合
- **记账**：虚拟盘（数学验证用）和实盘（用户真实下注后手动登记）分开跟踪

技术栈：FastAPI + SQLite + React（Vite）+ APScheduler

## 重要边界（这条是产品定位，不是技术限制，请勿越过）

**这个系统不做自动下注，也不应该被改造成自动下注。**

用户和上一个 Claude 会话明确讨论并达成一致：「实盘跟踪」的含义是**用户自己在博彩平台下完注之后，回来手动登记这笔注**，而不是让系统自动登录账户、自动提交投注。原因有二：

1. 几乎所有博彩平台的服务条款都禁止自动化下注，触发会导致封号
2. 把一个约 67% 准确率的模型接到自动扣款的真实账户上，是完全不同级别的风险

整个项目的基调是**精算式的诚实**——赌球长期是负期望值游戏，这个系统的价值在于"帮你看清楚这一注在数学上是否合理"，而不是"帮你必赢"。如果继续开发，请保持这个基调，不要往"稳赚"、"必胜"的方向包装。

## 快速启动

**双击 `start-mac.command`（Mac）或 `start-windows.bat`（Windows）**，会自动装依赖、打包前端、启动服务并打开浏览器。只有一个进程、一个端口。

或者手动：

```bash
python3 start.py
```

开发模式（前端热更新）仍可分开跑：

```bash
cd backend && uvicorn app.main:app --reload --port 8000
cd frontend && npm run dev     # 另开终端，访问 :5173
```

后端 API 交互式文档：http://127.0.0.1:8000/docs
