ValueBet · 本地运行说明
========================

要求：电脑装了 Python 3.10 以上。不需要 Node.js——前端已经打包好了。

启动
----
  Windows : 双击 start-windows.bat
  Mac     : 双击 start-mac.command
  任何系统 : 打开终端，cd 到这个文件夹，运行  python3 start.py

首次运行会自动装后端依赖（一两分钟）。启动后会打印两个地址：

  本机  → http://127.0.0.1:8000
  手机  → http://192.168.x.x:8000     ← 手机连同一个 Wi-Fi 打开这个

关掉窗口就停止服务。

手机连不上的话
--------------
八成是防火墙。
  Windows：首次启动会弹「是否允许 Python 访问网络」，选「专用网络」允许。
           错过了就去「Windows Defender 防火墙 → 允许应用通过防火墙」勾上 Python。
  Mac    ：系统设置 → 网络 → 防火墙，允许传入连接。
还要确认手机和电脑连的是同一个 Wi-Fi。

现在是休赛期
------------
今天（2026-07-31）没有即将开赛的比赛：世界杯 7月19日刚结束，
各大联赛 5 月就完赛了，2026-27 赛季的赛程数据源还没发布。
8 月中下旬联赛回归、数据源发布后，系统会在下次更新时自动接上，不用改任何东西。

这期间「💰 价格策略」页照常可用——它只要你手输赔率，不依赖赛程。

先做哪件事
----------
去「💰 价格策略」页，用默认的「同场三个赔率」模式：把 BK8 对某场比赛开的
主胜/平局/客胜三个赔率填进去，就能判断。不需要查任何行情。

系统从这三个数算出 BK8 的抽水，抽水才是真正吃掉优势的量：
  抽水 < 1.95%  → 押热门有得赚（薄，但为正）
  抽水 6.4%     → -3.28%，选对方向也是亏的

先拿 10 场比赛试一下，看看 BK8 的抽水通常是多少。这一个数就能告诉你
这套策略在你的平台上到底成不成立——多数软盘 1X2 抽水 5-7%，
只有锐盘和交易所能到 2% 附近。要有心理准备结论可能是「不成立」。
